# Support

Use GitHub Discussions for setup questions, UGREEN model compatibility, and
general troubleshooting. Use GitHub Issues for reproducible defects in files
maintained by this project.

When reporting a problem, include:

- UGREEN model and CPU architecture (`uname -m`)
- UGOS and Docker/Compose versions
- Image tag or source commit
- Redacted Compose configuration
- `docker compose ps` and relevant container logs
- Exact reproduction steps and expected behavior

Do not post passwords, API keys, tunnel tokens, SSH keys, public hostnames, or
unredacted environment files. Upstream code-server, CLI, Docker, extension, and
provider-specific bugs may be redirected to the relevant upstream project.
